# Margam: The TS Bus Guide

Maargam is a lightweight, zero-cost, offline-first mobile app engineered specifically for daily Hyderabad commuters relying on TGSRTC buses.

It strips away the clutter of payment super-apps to focus purely on navigation without requiring an internet connection.

Features:
Offline Route Search (instant lookup for bus numbers showing complete paths)
Stop Timetables for different City Bus Routes.

DATA SOURCE

The bus schedule and routing data displayed within this app are sourced from the official General Transit Feed Specification (GTFS) datasets published publicly by the Government of Telangana Open Data Portal.
